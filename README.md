# typeover

Learn Go from your TypeScript knowledge.

A bilingual learning site that teaches Go to TypeScript developers through
side-by-side translation, multiple choice, fill-in-the-tile, and code-runner
exercises.

## Stack

- [Astro 5/6](https://astro.build) — content-first with islands
- [Solid](https://www.solidjs.com) — tiny reactive islands
- [Tailwind 4](https://tailwindcss.com) — CSS-first design tokens
- [Yaegi](https://github.com/traefik/yaegi) (planned) — Go interpreter in WASM, run in browser via Web Worker
- pnpm + Vercel

## Development

```bash
pnpm install
pnpm dev
```

See [`design-docs/`](design-docs/) for project rationale, pedagogy, and design
system principles.
